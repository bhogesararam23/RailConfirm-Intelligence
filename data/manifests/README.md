# Dataset manifests

Place one manifest per candidate dataset here only when its contents are safe to publish. Use a descriptive ID, not a passenger name or PNR.

Manifests record source and provenance metadata; they do not grant rights to the data. Every candidate must be reviewed against docs/data/DATASET_INTAKE_CHECKLIST.md. Do not copy a private licence, agreement or provider response into this public folder if it is not intended for disclosure.

A manifest may point to a locally held file path that is ignored by Git, but never include private credentials or a public link that exposes personal data.
